# Hapi на Deno

Пример приложения [Hapi](https://hapi.dev/) на [Deno](https://deno.com/).

## Параметры деплоя

Выберите рантайм **Deno**, фреймворк **Hapi** и тип приложения **backend**. Приложение запускается как сервер.

| Параметр | Значение |
| --- | --- |
| Фреймворк | Hapi |
| Версия Deno | 2.7.14 |
| Тип приложения | `backend` |
| Команда запуска | `deno task start` |

## <a name="dev"></a>Локальный запуск проекта

```bash
# запуск приложения
deno task start
```
